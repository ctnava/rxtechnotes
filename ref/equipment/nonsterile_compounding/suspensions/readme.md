# Suspensions

A **suspension** is a *two‑phase, heterogeneous* liquid dosage form containing **insoluble solid particles dispersed in a liquid vehicle**.

> 📌 Unlike solutions, the drug is **not dissolved**; it is **dispersed**.

---

## 🔑 Definition

A **suspension** consists of:

- **Dispersed phase** → the **insoluble solid particles**  
- **Dispersion medium** → the **liquid vehicle** (usually aqueous)

Characteristics:

- Particles **settle over time** (sedimentation)  
- Must be **shaken well** before use  
- Particle size must be **controlled** to prevent caking  
- Requires **excipients** to stabilize the system

---

## 🧪 Flocculating Agents

**Flocculating agents** promote the formation of **loose, fluffy aggregates** (“flocs”) that:

- Settle **rapidly**  
- Are **easy to redisperse**  
- Prevent formation of a **hard cake** (irreversible sediment)

Common flocculating agents:

- Electrolytes (e.g., **sodium chloride**)  
- Surfactants  
- Polymers (e.g., **carboxymethylcellulose**, **gelatin**)  

📌 *Flocculation = controlled aggregation → better redispersibility.*

---

## 🧴 Thickening Agents (Viscosity Enhancers)

Thickening agents increase the **viscosity** of the dispersion medium to:

- Slow sedimentation  
- Improve uniformity  
- Enhance mouthfeel (oral suspensions)

Common agents:

- **Methylcellulose (MC)**  
- **Carboxymethylcellulose (CMC)**  
- **Xanthan gum**  
- **Tragacanth**  
- **Acacia**  
- **Carbomers**

🛡️ *Higher viscosity = slower settling = more stable suspension.*

---

## 🧪 Levigating Agents

Used to **reduce particle size** before incorporation into the vehicle.

A levigating agent is mixed with the powder to form a **smooth paste**.

Common levigating agents:

- **Glycerin** (for aqueous systems)  
- **Propylene glycol**  
- **Mineral oil** (for oleaginous systems)  
- **PEG 400**

📌 Choose a levigating agent **compatible with the vehicle** (“like with like”).

---

## 🍓 Flavoring Agents

Used to improve **palatability**, especially for pediatric suspensions.

- Fruit flavors (cherry, grape, bubblegum)  
- Vanilla  
- Mint  
- Citrus oils  

🛡️ *Match flavor to drug profile:*

- Bitter drugs → **chocolate, mint**  
- Sour drugs → **citrus, berry**

---

## 🍬 Sweeteners

Used to mask unpleasant taste and improve patient acceptance.

**Nutritive sweeteners:**

- Sucrose  
- Sorbitol  
- Mannitol  

**Nonnutritive sweeteners:**

- Aspartame  
- Saccharin  
- Sucralose  

📌 Polyols (sorbitol, glycerin) also add **viscosity**.

---

## 🎨 Coloring Agents

Added to match flavor or improve appearance.

- FD&C dyes  
- Natural colorants (e.g., caramel, beet extract)

🛡️ Must be **compatible**, **nonreactive**, and **safe for intended route**.
